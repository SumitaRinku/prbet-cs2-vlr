# 赛程图生成与验证

首页和赛事回看共用一套赛程图。页面依次加载 `bracket-graph.js`、`bracket.js`、`bracket-ui.js`，视觉规则集中在 `bracket.css`。更新部署时应同时发布这三个脚本、样式表与对应 HTML，避免只替换旧的 `bracket.js`。

## 数据与布局

- `bracket-graph.js` 是无 DOM、无数据库依赖的纯函数模块，负责赛果解析、关系校验、拓扑分层及坐标计算。测试直接复用相同模块。
- `bracket.js` 合并本地比赛与官方节点，识别赛制并生成卡片。官方快照遗漏的本地比赛继续显示，以虚线边框标识其晋级关系尚待确认。统计仍按本地比赛计算。
- 轮次先满足依赖约束，再参考名称提示；目标比赛始终位于来源比赛之后。异常循环、悬空边和非法边会被报告，不会让整张图崩溃或悄悄丢掉比赛。
- 双败图使用同一个画布，胜者组、败者组、总决赛共享横向轮次。仅绘制胜者晋级线；败者去向不画线，在有有效败者去向且赛果已确认的来源比赛中，将 ↓ 显示于败方比分左侧。败者关系仍参与依赖校验和轮次计算。季军赛单独展示。
- 已结束但无比分的比赛显示“—”。胜者 ID 有效时优先使用胜者 ID，缺失时才从已知且不同的比分判断；未知赛果保持中性，避免显示 0:0 或把双方都标为负方。
- 瑞士轮保留独立的战绩桶展示。标准 16 队的 33 场骨架继续使用现有识别规则；本次没有把未知赛制自动套入该骨架。

## 交互

轮次箭头用于横向浏览，“定位当前”优先寻找进行中的比赛，也会调整图内纵向位置。悬停或键盘聚焦比赛时，高亮其上游和下游关系；点击空白处、退出图或使用导航按钮后恢复总览。遵循系统减少动态效果的偏好。

暗色模式采用 HLTV 风格的灰蓝平面卡片：小圆角、无厚重阴影，胜方使用明亮队名、绿色比分和侧边标记，负方保留足够的文字对比度。参考来源为本目录的 `bracket-reference-HLTV.txt`（单败、小组双败、双败、瑞士轮和 EPL 淘汰赛 DOM）与 `IEM Cologne 2025 overview _ HLTV.org.mhtml`（含完整样式快照）。画布使用 #364250，卡片使用更深的 #2d3844；桌面比赛卡片高度 60px，手机 56px。未复制其页面或商标素材。

点击淘汰赛、双败或 GSL 轮次标题可折叠本列，再次点击恢复，也支持 Enter／空格。折叠列宽 72px，隐藏队名但保留队标、比分和败者箭头，后续列与连线同步收紧。容器宽度不足时自动折叠，优先级为已完成列、已完成／TBD 混合列、普通未赛列、进行中列；只折叠容纳内容所需的列。变宽时自动展开，手动设置的列保留用户选择。如果所有列都折叠后仍不够宽，保留横向滚动。MHTML 可以核对断点规则，但不能据此声称已完成 HLTV 实时手机页面的交互验证。

瑞士轮参考 `HLTV-swissround.png`，用等宽列在容器内展示完整轮次；窄容器使用队标和比分，保留完整晋级／淘汰区。320px 真实赛事验证显示全部五轮、33 场比赛、16 个结果队伍，图高约 386px，无横向溢出。仅保留这一种自适应布局，不提供总览／详细视图切换。轮次标题去掉底板，与本列卡片水平居中；比赛卡片和结果区跟随明暗主题。隐藏队名时仍提供完整的辅助技术名称和队名提示。

LIVE 使用独立红色状态，避免与绿色胜方结果混淆。淘汰赛卡片显示红色细边和卡片上方的圆点标签；瑞士轮卡片显示红色细边和角落小红点，工具条统一解释 LIVE 含义，比赛按钮的辅助名称也包含“进行中”。状态标记不闪烁、不遮挡队标和比分，配色跟随明暗主题。

横向滚动时，两侧渐隐提示还有未显示内容，工具条显示当前可见轮次范围；到达首尾后禁用对应方向按钮。容器大小改变、阶段展开及新内容插入后会重新计算折叠及溢出状态。移动端取消图内纵向高度上限，纵向浏览交给页面，避免陷入双方向嵌套滚动。

## 本地验证

真实数据的只读预览可运行 `node scripts/preview-project.js`，打开 `http://127.0.0.1:4319/`。该服务复用比赛、排行榜和赛事读取接口，数据库只读，不运行初始化或同步任务，不支持登录和写入。主页的读取接口须与赛事接口一起挂载，不能只挂载 `/api/tournaments`。

```powershell
node scripts/preview-brackets.js
```

打开 `http://127.0.0.1:4318/preview`，可查看单败、双败、GSL、瑞士轮示例以及 390px 手机预览。该服务只监听本机，使用构造数据，不连接数据库或 PandaScore。实际手机视口测试可打开 `/preview?mobile=1`。预览完毕按 Ctrl+C 停止服务。

```powershell
node --test test/bracket.test.js test/bracket-graph.test.js test/bracket-sync.test.js
```
