## 启动流程（server/index.js）

```
require('dotenv').config()
    │
    ├─ ensureDatabase()                 # 建表 + 列迁移 + 历史修复 + 默认管理员
    ├─ express() / trust proxy
    ├─ requestLogger
    ├─ CORS：ALLOWED_ORIGINS 白名单；非生产环境放行 localhost/127.0.0.1
    ├─ express.json() / urlencoded()
    ├─ 挂载 11 个 /api/* 路由 + /api/health
    ├─ serveHtml 路由（/, 各 .html, /admin, /admin/）
    ├─ express.static(publicDir)
    ├─ /uploads 静态目录（data/uploads）
    ├─ app.get('*') → index.html
    ├─ 全局错误处理
    └─ app.listen(PORT, HOST)           # 默认 127.0.0.1:3000
        └─ startPandascoreSyncService()
             ├─ 立即比赛同步 startup + 每 5 分钟 scheduled
             └─ 15 秒后赛事预告 + 每 6 小时 preview
```

关键点：

- `HOST` 默认 `127.0.0.1`：生产必须经 Nginx 反代，防止公网直连伪造 `X-Forwarded-For` 绕过限流。
- `trust proxy` 默认 `1`，使 `req.ip` 取真实客户端 IP。
- HTML 路由位于 `express.static` 之前；HTML 响应设置 `Cache-Control: no-store` 并忽略条件请求，避免部署后浏览器命中 304 复用旧的空白页面。
- CORS 白名单命中失败返回 **403**（带 `errorId`），不再被兜底成 500。

## 请求处理流程（以「提交预测」为例）

```
POST /api/matches/42/predictions
  1. authenticateToken           # Bearer JWT → req.user（401 失败）
  2. 比赛存在 / 非 TBD / upcoming / betting_enabled / 未开赛
  3. predicted_winner_id ∈ {team1_id, team2_id}
     isValidScore(s1, s2, format) 且比分方向与胜者一致
  4. 已有预测 → UPDATE；否则 INSERT（UNIQUE(user_id, match_id)）
  5. 写入 prediction_history（created / updated）
  6. 响应 201 / 200
```

## 模块依赖关系

### 后端

```
server/index.js
 ├── config/init-db.js ── config/bot-schema.js
 │                    └── utils/settlement.js ── utils/scoring.js
 ├── services/pandascoreService.js ─┬─ services/settings.js
 │                                  ├─ utils/settlement.js
 │                                  └─ config/database.js
 └── routes/*
      ├── config/database.js               # 全局 SQLite 单例
      ├── middleware/auth.js / rateLimit.js / errorHandler.js
      ├── utils/scoring.js / settlement.js / validators.js / matchValidation.js
      ├── utils/predictionHistory.js       # matches 路由记录预测变更
      ├── services/pandascoreService.js    # admin（同步/预告）
      ├── services/settings.js             # admin（预告天数）、tournaments（预览窗口）
      └── services/botCommands.js / botSettlement.js  # bot 路由
```

- `config/database.js` 为全局单例：加载即建连接，所有模块共享。
- `utils/scoring.js` 零依赖纯函数，被 routes / services / scripts 共用。
- `init-db.js` 反向依赖 `settlement.js`，启动修复历史数据时立即结算。
- `settings.js` 只依赖数据库，管理端读写、同步服务与公开预告接口共用。

### 前端脚本加载

```
所有页面：theme.js（最早）→ tournament-logos.js
   ├── index.html        + shared.js → h2h.js → share.js → bracket.js → app.js
   ├── tournaments.html  + shared.js → h2h.js → bracket.js → tournaments.js
   ├── leaderboard.html  + shared.js → leaderboard-page.js
   ├── profile.html      + shared.js → share.js → profile.js → bot-account.js
   ├── teams.html        + shared.js → teams.js
   └── admin/index.html  + tournament-logos.js → admin.js（独立 state/api）
```

- `bracket.js` 是纯函数库，无 DOM 副作用；依赖宿主页提供的 `escapeHtml` / `logoHtml` / `focusTournamentMatch`。
- `h2h.js`、`share.js` 为跨页组件；`shared.js` 统一认证、API、logo 与预测详情渲染。
- `tournament-logos.js` 负责厂牌 logo、队标暗色换源，以及暗色模式下黑色赛事 logo 的亮度采样与反色。
- `theme.js` 切换主题后派发 `theme-changed`，相关模块即时换源/切换反色。

## 外部依赖

### npm 运行时依赖

| 包 | 用途 | 使用位置 |
| --- | --- | --- |
| express | Web 框架 | server/index.js、全部 routes |
| better-sqlite3 | SQLite 同步驱动 | config/database.js |
| bcryptjs | 密码哈希 | auth、admin、init-db |
| jsonwebtoken | JWT | middleware/auth.js |
| qrcode | 分享图二维码 | routes/qrcode.js |
| cors | CORS | server/index.js |
| dotenv | .env | server/index.js、CLI 脚本 |

### Node 内置模块

- `http` / `https` / `dns` / `net` — 队标代理（DNS 校验、固定 IP 连接防 rebinding）
- `crypto` — 随机管理员密码、JWT 密钥、requestId
- `fs` / `path` — 数据库目录、密钥落盘、HTML 读取、logo 上传
- 全局 `fetch`（Node ≥ 18）— PandaScore 同步、告警 webhook

### 外部服务

- **PandaScore REST API**（默认 `https://api.pandascore.co`）
  - 鉴权：`Authorization: Bearer <token>`
  - 比赛：`/csgo/matches`、`/valorant/matches`；每页 100，最多 10 页；`range[begin_at]` 手工拼 query（逗号需字面量）
  - 预告：`/csgo/series/upcoming`、`/valorant/series/upcoming`；每页 100，最多 10 页
- **NapCat / OneBot**：`bot/` 独立进程，读取 `/api/bot/schedule`、调用 `/api/bot/command`、轮询 `/api/bot/settlements`

## 部署拓扑（生产）

```
用户 ──HTTPS──▶ Nginx（80/443）
                 │ proxy_pass http://127.0.0.1:3000
                 ▼
               PM2 守护 node server/index.js（单实例）
                 │ SQLite 同步读写
                 ▼
               data/database.sqlite + data/.jwt_secret + data/uploads
                 │ 定时 fetch（比赛 5 分钟 / 预告 6 小时）
                 ▼
               PandaScore API

QQ 群 ◀── NapCat（独立进程）──▶ Node bot/run.js ──HTTP──▶ /api/bot/*
```

单进程假设：限流（内存 Map）、比赛/预告同步互斥（模块级标志）、定时器均只在单实例内有效。
