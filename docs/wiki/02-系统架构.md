## 启动流程（server/index.js）

```
require('dotenv').config()
    │
    ├─ ensureDatabase()               # config/init-db.js：建表（IF NOT EXISTS）
    │                                 # + 列探测式迁移 + 弃权局回填 + 默认管理员
    ├─ const app = express()
    ├─ app.set('trust proxy', TRUST_PROXY)   # 默认 1（单层 Nginx）
    ├─ CORS（ALLOWED_ORIGINS 白名单或全开）
    ├─ express.json() / express.urlencoded()
    ├─ 挂载 8 个 /api/* 路由 + /api/health
    ├─ serveHtml 路由（/, /tournaments.html, ..., /admin）—— 注入 ICP 备案号
    ├─ express.static(publicDir)
    ├─ app.get('*') → index.html      # SPA 式兜底
    ├─ 全局错误处理（500 JSON）
    └─ app.listen(PORT, HOST)         # 默认 127.0.0.1:3000
        └─ startPandascoreSyncService()   # 监听回调里启动定时同步
```

关键点：

- `HOST` 默认 `127.0.0.1`——生产必须经 Nginx 反代，防止公网直连伪造 `X-Forwarded-For` 绕过登录限流。
- `trust proxy` 默认 `1`，配合 `req.ip` 让限流拿到真实客户端 IP。
- HTML 路由放在 `express.static` **之前**，保证注入备案号后的页面优先生效。

## 请求处理流程（以「提交预测」为例）

```
POST /api/matches/42/predictions
  1. authenticateToken            # 解析 Bearer JWT → req.user（401 失败）
  2. 取 match 校验：
     - 存在性；非 TBD 对阵
     - status === 'upcoming' && betting_enabled
     - match_time > now（开赛后拒绝）
  3. 参数校验：
     - predicted_winner_id ∈ {team1_id, team2_id}
     - isValidScore(s1, s2, format)     # utils/scoring.js
     - 比分胜负方向与 predicted_winner_id 一致
  4. 已有预测 → UPDATE；否则 INSERT    # UNIQUE(user_id, match_id)
  5. 响应 201 { message: '预测已提交' }
```

## 模块依赖关系

### 后端（require 方向，自上而下）

```
server/index.js
 ├── config/init-db.js ──── utils/settlement.js ──── utils/scoring.js
 ├── services/pandascoreService.js ─┬─ utils/settlement.js
 │                                  └─ config/database.js
 └── routes/*
      ├── config/database.js          # 所有路由直接持有 db 单例
      ├── middleware/auth.js
      ├── middleware/rateLimit.js      # 仅 auth.js 路由使用
      ├── utils/scoring.js             # matches / admin（比分校验）
      ├── utils/settlement.js          # admin（录入赛果/弃权/删除后重算）
      └── services/pandascoreService.js# 仅 admin.js（手动同步/状态）
```

- `config/database.js` 是**全局单例**：模块加载即建连接（`data/` 目录自动创建），所有文件 `require` 到同一实例。
- `utils/scoring.js` 为纯函数模块，无任何依赖（被 routes、services、scripts 共用）。
- `init-db.js` 反向依赖 `settlement.js`：启动时回填历史弃权局要立即结算。

### 前端（脚本加载与全局共享）

```
所有页面均引入 shared.js（提供 sharedState/sharedApi/logoHtml/...）
   ├── index.html        + app.js         （内部另有独立 api/logout 旧实现，页面自洽）
   ├── tournaments.html  + tournaments.js + bracket.js
   ├── leaderboard.html  + leaderboard-page.js
   ├── profile.html      + profile.js     （依赖 shared.js 的 gameName/logoHtml）
   ├── teams.html        + teams.js
   └── admin/index.html  + admin.js       （自带独立 state/api）
```

- `bracket.js` 是**纯函数库**：无 DOM 副作用、无页面状态，依赖各页提供的环境全局（`escapeHtml`、`logoHtml`、`focusTournamentMatch`）；被 `tournaments.js`（赛事详情）与 `app.js`（首页折叠面板）共用，并被 `test/bracket.test.js` 直接单测。
- 认证态：`localStorage` 的 `token` + `user`；`shared.js` 广播 `auth-changed` 自定义事件，页面监听后刷新数据。

## 外部依赖

### npm 运行时依赖（package.json）

| 包 | 用途 | 使用位置 |
| --- | --- | --- |
| express | Web 框架 | server/index.js、所有 routes |
| better-sqlite3 | SQLite 同步驱动 | config/database.js（唯一连接点） |
| bcryptjs | 密码哈希 | routes/auth.js、routes/admin.js、config/init-db.js |
| jsonwebtoken | JWT 签发/校验 | middleware/auth.js |
| cors | CORS 中间件 | server/index.js |
| dotenv | .env 加载 | server/index.js（入口处一次） |

### Node 内置模块

- `http` / `https` / `dns` / `net` — routes/images.js（logo 代理：DNS 解析校验、固定 IP 连接防 rebinding）
- `crypto` — init-db.js（随机管理员密码）、middleware/auth.js（随机 JWT 密钥）
- `fs` / `path` — database.js（data 目录）、auth.js（密钥落盘）、index.js（读 HTML）
- 全局 `fetch`（Node ≥ 18）— pandascoreService.js 拉取 PandaScore

### 外部服务

- **PandaScore REST API**（`https://api.pandascore.co`）
  - 鉴权：`Authorization: Bearer <token>`
  - 端点：`/csgo/matches`、`/valorant/matches`
  - 分页：`page[number]` + `page[size]`（每页 100，最多 10 页）
  - 时间范围：`range[begin_at]=start,end`（**手工拼 query**，避免 URLSearchParams 把逗号编码成 `%2C` 导致 400）

## 部署拓扑（生产）

```
用户 ──HTTPS──▶ Nginx（80/443）
                 │ proxy_pass http://127.0.0.1:3000
                 ▼
               PM2 守护 node server/index.js（单实例）
                 │ better-sqlite3 同步读写
                 ▼
               data/database.sqlite + data/.jwt_secret
                 │ 定时 fetch
                 ▼
               PandaScore API
```

单进程假设贯穿设计：限流（内存 Map）、同步互斥（模块级 `running` 标志）、`setInterval` 定时器均只在单实例内有效。
