# 05 · 前端模块详解

前端为**原生多页应用**（MPA）：6 个 HTML 入口 + 各自脚本，无框架、无构建。公共能力收敛在 `theme.js`、`tournament-logos.js`、`shared.js`、`h2h.js`、`share.js`，可视化在 `bracket.js`（纯函数库）。

## 页面与脚本总览

| 页面 | 样式 | 脚本（加载顺序） | 职责 |
| --- | --- | --- | --- |
| `index.html` | style.css | theme → tournament-logos → shared → h2h → share → bracket → `app.js` | 首页：比赛列表、游戏/赛事/状态筛选、登录注册、详情预测、H2H、折叠赛程图、分享 |
| `tournaments.html` | style.css + hub.css | theme → tournament-logos → shared → h2h → bracket → `tournaments.js` | 赛事回看：未来赛事预告 → 赛事列表/详情 → 赛程图、赛事榜、预测流水 |
| `leaderboard.html` | style.css | theme → tournament-logos → shared → `leaderboard-page.js` | 排行榜：游戏/赛事筛选、分页、CSV、用户明细 |
| `profile.html` | style.css + profile.css | theme → tournament-logos → shared → share → `profile.js` → `bot-account.js` | 个人中心：记录筛选、统计、分享、公开开关、QQ 绑定、改密 |
| `teams.html` | style.css + hub.css | theme → tournament-logos → shared → `teams.js` | 队伍中心：列表 → 详情（统计、履历名次、近期比赛） |
| `admin/index.html` | style.css + admin.css | theme → tournament-logos → `admin.js` | 管理后台：概览/比赛/赛事/队伍/用户/预测 + 同步工具条 |

## 公共模块

### `theme.js`

- IIFE 初始化 `html[data-theme]`（localStorage > 系统偏好），同步 `colorScheme`。
- 向 `#userPanel`（后台为 `#auth`）追加 `#themeToggle`；点击切换并派发 `theme-changed`。
- 用户面板重渲染时会把 `#themeToggle` 重新 append，避免丢失。

### `tournament-logos.js`

- `TOURNAMENT_LOGOS`：赛事名关键词 → 本地厂牌 logo；Game Changers 排除；未命中不显示。
- 优先级：管理员上传的 `/uploads/` > 名称匹配；远端 URL 不使用。
- 暗色变体：同目录 `-dark` 文件，404 自动回退原图（`darkVariantMissing` 缓存）。
- **黑白 logo 自动反色**：`measureDarkLogo()` 用 24×24 canvas 采样，平均亮度 < 96、亮色像素占比 < 15% 且彩色像素（HSV 饱和度 ≥ 0.25）占比 < 50% 才判定为需反色的黑白 logo；暗色主题下加 `tournament-logo-invert`，`style.css` 对所有赛事 logo 展示位统一应用 `invert(1) hue-rotate(180deg)`（主页卡片 / 筛选 chip / 预告 / 回看页 / 管理后台）。彩色 logo（如红色 VCT/PGL）不反色，避免颜色变浅。换源或主题切换时重新采样。
- 队标暗色换源：`data-team-logo` + `data-light`/`data-dark`，失败回退亮色、再失败显示 `TEAM` 占位。

### `shared.js`

| 导出 | 说明 |
| --- | --- |
| `sharedState` | `{token,user}`，初始化自 localStorage |
| `sharedApi(path, options)` | 自动 Bearer/JSON；非 auth 路径 401 清登录态并抛「登录已过期」 |
| `renderSharedUser()` | 渲染 `#userPanel`：未登录为 `form.auth-form`（用户名/密码/登录/注册），登录态显示用户信息与退出/后台入口 |
| `sharedLogin/Register/Logout` | 认证三件套，成功后派发 `auth-changed` |
| `gameName` / `formatDateTime` | 通用格式化 |
| `proxiedLogoUrl` / `logoHtml` | 队标代理与暗色属性 |
| `tournamentNameHtml` | 赛事简称双 span（移动端或长名称切换） |
| `renderMatchPredictionDetail` | 已结算比赛预测详情卡（主页/回看页共用） |

### `h2h.js`

`showMatchHead2Head(matchId)`：请求 `GET /matches/:id/head2head`，渲染双方近况与交手记录；运行时适配 `api`/`sharedApi`、`logo`/`logoHtml`。

### `share.js`

`sharePrediction(matchId)`：宿主页通过 `window.getMatchForShare` / `window.getShareContext` 提供数据；FontFace 加载 MiSans → 并行加载队标/品牌/二维码 → 1080×1080 canvas 合成 → 弹窗展示，支持下载/长按保存。

### `bracket.js`（纯函数）

无 DOM 副作用，依赖宿主页 `escapeHtml` / `logoHtml` / `focusTournamentMatch`。

```
matches[] → buildTournamentStages → stages[]
  → swissDiagram / doubleElimDiagram / playoffDiagram
```

- 阶段识别：`stage_external_id/slug` 优先 → 名称归一化 → 日期兜底。
- 瑞士轮 16 队骨架与 3-0/3-1/3-2 晋级桶；双败 UB/LB 泳道与轮次对齐；单败按显式位置排序。
- 移动端窄列：整轮未定或已结束可收窄；活跃列全宽。
- 卡片角标：LIVE / 未开赛时间；TBD 与已结束不显示。
- `buildBracketModel` 输出 diagnostics，测试断言渲染无损。

## 各页面

### 首页 `app.js`

- `state` 含 token/user、筛选、`matchesRequestId`/`bracketRequestId` 竞态令牌。
- `loadAll()` 并行拉 `/matches/upcoming` 与赛程图，丢弃过期响应。
- 比赛按赛事分组；组标题链接到 `/tournaments.html?tournament=<id>`。
- 比赛卡片：队标/短名、比分或 VS、时间、赛制、预测人数、H2H、我的预测（含分享）。
- 详情弹窗：`possible_scores` 驱动的胜者 + 比分表单。
- 分享钩子：`getMatchForShare` / `getShareContext`。

### 赛事回看 `tournaments.js`

- **未来赛事预告**：请求 `GET /tournaments/previews`，按游戏过滤展示赛事名/logo/日期，可收起（localStorage `previewCollapsed`）；进入赛事详情时隐藏。
- 列表：卡片/紧凑视图，赛事 logo、游戏、级别、进度与统计。
- 详情：`GET /tournaments/:id` → 吸顶阶段导航 → 赛程图 + 赛事榜 + 预测流水。
- `?tournament=<id>` URL 持久化；`focusTournamentMatch` 定位高亮；回到顶部悬浮按钮。

### 排行榜 `leaderboard-page.js`

游戏/赛事筛选、分页表格、CSV 导出、用户得分明细弹窗（增量加载）。

### 个人中心 `profile.js` + `bot-account.js`

- 记录筛选：状态、游戏、赛事；分页增量加载。
- 统计摘要、分享桥接（`getMatchForShare` / `getShareContext`）。
- 预测公开开关：`PUT /auth/visibility`（`predictions_public`）。
- QQ 绑定：`bot-account.js` 调 `/api/bot-account` 查询/生成绑定码/解绑。
- 修改密码：`PUT /auth/password`，两次输入一致、长度 ≥6。

### 队伍中心 `teams.js`

搜索、游戏筛选、排序（localStorage 持久化）；详情含 stats、赛事履历名次、近期比赛；`?team=<id>&sort=` 持久化。

### 管理后台 `admin.js`

- 独立 `state` 与 `api()`（401 处理同 shared）；`TABS = overview / matches / tournaments / previews / teams / users / predictions`，hash 路由。
- 每页 `PAGE_SIZE = 50`，表格「显示更多」增量渲染；行内操作统一 `data-act` 事件委托。
- **同步工具条**：同步状态、手动比赛同步、刷新数据；**预告前瞻天数输入（7–365）+ 保存 + 立即刷新预告**；预告状态与比赛同步状态分开显示。
- 概览：计数卡片、待结算比赛、同步信息。
- 赛事：CRUD + 简称/级别 + 启用禁用 + logo 上传/清除。
- 预告：列出全部同步项（含已隐藏），逐项切换前台显示/隐藏，可按显示状态与名称筛选。
- 比赛：CRUD、录赛果、弃权、betting 开关；录入后 `result_locked` 防同步覆盖。
- 用户/预测：管理操作与删除后重建总分。
- 样式前缀统一 `ops-`（`admin.css`），避免 AdBlock 的 `[class^="ad-"]` 通用规则把整页隐藏。

## 静态资源与交互约定

- HTML 由服务端注入 ICP 备案号；HTML 响应 `no-store`，JS/CSS 由 `express.static` 走 ETag 协商。
- `/uploads` 提供管理员上传的赛事 logo；`data/uploads` 不存在时 fallthrough。
- 所有插值经 `escapeHtml`；远程队标经 `/api/images/team-logo` 代理。
- 移动端顶栏：≤520px 时登录表单压成单行、主题按钮绝对定位到品牌行右侧；已登录用户名超长省略，按钮不拉伸。
- 筛选与视图状态持久化：`gameFilter`、`homeTournamentFilter`、`homeStatusFilter`、`tournamentViewMode`、`tournamentBrandFilter`、`previewCollapsed`、`teamSort`、`adminGameFilter`、`theme`。
