# 03 · 数据库设计

- 引擎：SQLite（better-sqlite3，同步 API），库文件 `data/database.sqlite`。
- 连接：`server/config/database.js` 模块级单例，加载时自动创建 `data/`，`foreign_keys = ON`。
- 建表与迁移：`ensureDatabase()`（`server/config/init-db.js`）+ `ensureBotSchema()`（`server/config/bot-schema.js`），`CREATE TABLE IF NOT EXISTS` + `PRAGMA table_info` 列探测，**每次启动执行**。

## 实体关系（简化）

```
users ──< predictions >── matches >── tournaments
  │            │              │
  │            └── teams      └── teams（team1 / team2 / winner）
  ├──< prediction_history
  └──< bot_bind_codes（1:1） / bot_bindings（1:1）

matches ──< bot_settlement_state / bot_settlement_events
app_settings、sync_runs、tournament_previews、bot_sync_state、bot_command_receipts、bot_group_members 为独立表
```

- 一人一场最多一条预测：`predictions UNIQUE(user_id, match_id)`。
- 删除赛事 → 级联删比赛与预测；删除比赛/用户 → 级联删预测；删除队伍 → 被引用比赛级联删除（`winner_team_id` 为 SET NULL）。
- 删除用户/比赛/预测后必须 `recalculateUserScores()` 重建总分。

## 启动迁移与数据修复（ensureDatabase）

1. **建表**：全部表 + 索引 `IF NOT EXISTS`。
2. **列迁移**（幂等）：
   - `teams.game_type`、`teams.dark_logo_url`
   - `tournaments.is_active`、`name_locked`（pandascore 来源置 1）、`logo_url`、`short_name`、`tier`
   - `users.token_version`、`users.predictions_public`
   - `matches.stage_name`、`stage_slug`、`stage_external_id`、`is_forfeit`、`result_locked`、`time_confirmed`
   - `predictions.streak_bonus` 若存在则删除，并按基础分重建总分（连胜机制已移除）
3. **历史弃权回填**：`cancelled + winner + is_forfeit=0` → 改为 finished、1-0、不计分，逐场结算。
4. **主客对调修复**：预测比分隐含胜者与 `predicted_winner_id` 不一致的存量记录对调比分并重新结算。
5. **默认管理员**：`ADMIN_USERNAME`（默认 `admin`）不存在则创建，密码取 `ADMIN_PASSWORD` 或随机打印一次。

## external_id 规范与升级

早期 external_id 为裸 PandaScore id，现规范为 `<game_type>:<id>`。`findOrUpgradeExternalId()` 先按规范 id 查，未命中时按裸 id 查并原地升级。历史重复由 `scripts/cleanup-pandascore-duplicates.js` 清理（默认 dry-run）。

## 数据完整性要点

- **总分是重建值不是累加值**：仅 `recalculateUserScores()` 可写 `users.total_score`。
- **points_earned 三态**：NULL 待结算、0 已结算 0 分、>0 得分；排行榜/胜率/H2H/队伍履历统一过滤 `is_forfeit=0`。
- **结果锁定**：`result_locked=1` 的比赛，PandaScore 同步只补阶段元数据，不覆盖比分/胜者/状态。
- **预告与比赛隔离**：远期赛事只进 `tournament_previews`，不会因外键级联影响预测或积分。
