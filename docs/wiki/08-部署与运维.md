# 08 · 部署与运维

## 前置要求

- Node.js ≥ 20（内置 `fetch`）
- PandaScore API Token（<https://dashboard.pandascore.co>）
- better-sqlite3 编译工具链（Linux：`build-essential` + `python3`）
- 可选：NapCat / OneBot 环境（QQ 群机器人）

## 本地运行

```bash
npm install
npm run init-db      # 建表 + 迁移 + 默认管理员
npm start            # http://127.0.0.1:3000
```

> Windows 下 better-sqlite3 编译失败时，安装 Visual Studio Build Tools，或使用与 Node 版本匹配的预编译二进制。

入口：

| 地址 | 说明 |
| --- | --- |
| `/` | 首页 |
| `/tournaments.html` | 赛事回看 + 未来赛事预告 |
| `/leaderboard.html` | 排行榜 |
| `/profile.html` | 个人中心 |
| `/teams.html` | 队伍中心 |
| `/admin/` | 管理后台 |
| `/api/health` | 健康检查 |

默认管理员：`ADMIN_USERNAME`（默认 `admin`）；密码取 `ADMIN_PASSWORD`，否则首次初始化随机生成并打印一次。

启动后若配置了 Token：立即同步比赛，此后每 5 分钟一轮；15 秒后同步赛事预告，此后每 6 小时一轮。新同步赛事默认 `is_active=0`，需后台启用。

## 环境变量（.env，根目录）

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 监听端口 |
| `HOST` | `127.0.0.1` | 监听地址；直连部署才设 `0.0.0.0` 并配合 `TRUST_PROXY=0` |
| `TRUST_PROXY` | `1` | 反代层数；单层 Nginx=1，直连=0，前面有 CDN 按层数调大 |
| `NODE_ENV` | — | `production` / `development`；非 production 放行本地 Origin |
| `JWT_SECRET` | 自动生成 | 留空时生成并持久化到 `data/.jwt_secret`（0600） |
| `ALLOWED_ORIGINS` | 全开 | CORS 白名单，逗号分隔；配置后仅允许这些来源 |
| `ADMIN_USERNAME` | `admin` | 默认管理员用户名 |
| `ADMIN_PASSWORD` | 随机 | 留空则初始化时随机生成并打印一次 |
| `ICP_NUMBER` | — | ICP 备案号（生产必填，否则 footer 不显示） |
| `ICP_LINK` | 工信部备案页 | 备案号链接 |
| `PANDASCORE_API_TOKEN` | — | PandaScore Token（必填，兼容旧名 `PANDASCORE_TOKEN`） |
| `PANDASCORE_BASE_URL` | `https://api.pandascore.co` | API 基址 |
| `PANDASCORE_SYNC_ENABLED` | `true` | 设 `false` 关闭比赛与预告定时任务 |
| `PANDASCORE_SYNC_INTERVAL_MS` | `300000` | 比赛同步间隔（下限 60000） |
| `PANDASCORE_SYNC_LOOKAHEAD_DAYS` | `7` | 比赛前瞻天数（代码上限 7） |
| `PANDASCORE_SYNC_RESULTS` | `true` | 设 `false` 关闭赛果同步 |
| `PANDASCORE_REQUEST_TIMEOUT_MS` | `20000` | 单次请求超时 |
| `PANDASCORE_PREVIEW_DAYS` | `180` | 赛事预告前瞻天数默认值；**管理后台设置优先** |
| `PANDASCORE_PREVIEW_INTERVAL_MS` | `21600000` | 预告刷新间隔（6 小时，下限 30 分钟） |
| `ALERT_WEBHOOK_URL` | — | 同步连续异常告警（Server酱 / Bark / 通用 JSON） |
| `BACKUP_KEEP` | `7` | `npm run backup` 保留份数 |
| `BOT_FEED_TOKEN` | — | 机器人接口 Token；未配置时 `/api/bot/*` 返回 503 |
| `BOT_COMMAND_GROUP_IDS` | — | 允许群内竞猜的 QQ 群号（逗号分隔） |
| `BOT_ADMIN_QQ_IDS` | — | 允许执行管理指令的 QQ 号（逗号分隔） |

`.env` 示例：

```bash
PORT=3000
HOST=127.0.0.1
TRUST_PROXY=1
NODE_ENV=production
JWT_SECRET=请替换为随机长字符串

ICP_NUMBER=豫ICP备XXXXXXXX号
PANDASCORE_API_TOKEN=你的PandaScoreToken
PANDASCORE_SYNC_ENABLED=true
PANDASCORE_SYNC_INTERVAL_MS=300000
PANDASCORE_SYNC_LOOKAHEAD_DAYS=7
PANDASCORE_SYNC_RESULTS=true
PANDASCORE_REQUEST_TIMEOUT_MS=20000
PANDASCORE_PREVIEW_DAYS=180
PANDASCORE_PREVIEW_INTERVAL_MS=21600000
```

> 赛事预告天数以管理后台「预告前瞻」设置为准（存 `app_settings`，重启不丢）；`PANDASCORE_PREVIEW_DAYS` 仅作为数据库无设置时的默认值。

## 生产部署（Linux + Nginx + PM2）

```bash
sudo apt-get update
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs build-essential python3

cd /home/admin/repo/prg_cs2_bet_new
npm install
npm run init-db
npm run sync:pandascore
npm install -g pm2
pm2 start server/index.js --name prg-cs2-bet-new
pm2 save
pm2 startup
```

防火墙只开放 80/443，**不要**对公网开放 3000：

```bash
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw delete allow 3000/tcp   # 若以前开过
```

Nginx：

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

## 数据与备份

| 路径 | 内容 | 说明 |
| --- | --- | --- |
| `data/database.sqlite` | 全部业务数据 | 核心备份对象 |
| `data/.jwt_secret` | JWT 持久化密钥 | 删除会导致全体重新登录（配置 `JWT_SECRET` 则不受影响） |
| `data/uploads/` | 管理员上传的赛事 logo | 运行时数据，需随数据库备份；同步不覆盖 |
| `data/backups/` | `npm run backup` 产物 | 默认保留 7 份 |
| `.env` | 全部敏感配置 | 需与数据库一起保留 |
| `public/fonts/` | MiSans woff2 子集 | 分享图 canvas 用，随仓库分发 |

建议 crontab 每日备份：

```bash
0 4 * * * cd /path/to/prg_cs2_bet_new && node scripts/backup-db.js >> data/backup.log 2>&1
```

恢复：`node scripts/restore-db.js data/backups/database-xxxx.sqlite`（恢复前自动生成 `.before-restore-*`）。

## 安全要点

| 项 | 措施 |
| --- | --- |
| 密码 | bcrypt（注册/重置 cost=10，默认管理员 cost=12） |
| JWT | HS256 + 30 天；`token_version` 改密即失效；固定 `algorithms:['HS256']` |
| 暴力破解 | 登录/注册/改密每 IP 15 分钟 20 次 |
| IP 伪造 | 默认只监听 127.0.0.1 + trust proxy |
| CORS | `ALLOWED_ORIGINS` 白名单；非 production 才放行本地地址 |
| 队标代理 | 白名单 + 内网 IP 拦截 + DNS 全记录校验 + 固定 IP + 重定向校验 + 大小/超时限制 |
| 上传 | 仅 PNG/JPEG/GIF/WebP（magic bytes），≤2MB，文件名服务端生成 |
| 机器人 | `BOT_FEED_TOKEN` 恒定时间比较；`/api/bot` 1 分钟 300 次 |
| XSS/SQL | 输出统一转义；全部 prepared statement |

## 运维 playbook

### 同步异常

1. `GET /api/admin/sync/status`：看 `configured`、`last_run`、`preview_last_run`。
2. `sync_runs.message` 含失败详情；「全部游戏拉取失败」多为 Token 或网络问题。
3. 手动 `POST /api/admin/sync/pandascore` 或 `npm run sync:pandascore` 复现。
4. `PANDASCORE_SYNC_LOOKAHEAD_DAYS > 7` 无效；改 `.env` 需重启进程。

### 赛事预告为空

1. 后台点「刷新预告」，看返回 message 与 `preview_last_run`。
2. 确认 `preview_days` ≥ 7；PandaScore 当前只公开少量 `series/upcoming`，数据源本身可能没有更远赛程。
3. 单游戏失败会保留该游戏旧预告；检查 Token 与网络。

### 页面空白 / 部署后样式旧

- HTML 已 `no-store` 并忽略条件请求，普通刷新即可拿新页面；仍异常时强刷或清站点数据。
- 管理后台若被 AdBlock 隐藏：现已使用 `ops-` 前缀，不再命中 `[class^="ad-"]`；极端情况检查扩展的自定义拦截规则。

### 积分 / 排行榜不一致

- 重新录入涉事比赛赛果（`PUT /admin/matches/:id/result`），事务内自动 `settleMatch + recalculateUserScores`。
- 删除预测/比赛/用户后总分由路由自动重建。

### 升级 / 重启

```bash
git pull
npm install
pm2 restart prg-cs2-bet-new
```

启动时 `ensureDatabase()` 自动完成建表、列迁移、弃权回填与主客对调修复；JWT 密钥持久化，正常重启不掉登录态。

### 单实例约束

限流（内存 Map）、比赛/预告同步互斥、定时器均为单进程设计。改用 PM2 cluster 或多实例时，需要把限流与同步互斥迁移到共享存储（Redis 等）。
