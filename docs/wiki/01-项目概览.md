# 01 · 项目概览

## 项目定位

PRBET 是一个**中文电竞赛事竞猜站点**（纯积分，无真实货币），核心闭环：

1. **同步**：PandaScore 近端赛程/赛果（过去 48 小时 ~ 未来 7 天，5 分钟一轮）与远期赛事预告（默认未来 180 天，赛事级、6 小时一轮）。
2. **竞猜**：用户注册登录后，在比赛开始前预测「胜者 + 双方比分」（BO1 / BO3 / BO5），可修改、可取消。
3. **结算**：比赛结束由同步自动结算，或管理员手动录入赛果 / 标记弃权；结算幂等可重算。
4. **排行**：总榜与赛事榜，支持 CSV 导出、用户得分明细。
5. **群机器人**：QQ 群每日赛程、昨日赛果、临赛提醒与群内竞猜（独立 `bot/` 进程 + NapCat，经 `/api/bot/*` 与站点交互）。

覆盖游戏：CS2、Valorant（`game_type` 区分，同表同逻辑复用）。

## 功能特性

### 用户侧

- 注册 / 登录 / JWT 鉴权；登录、注册、改密共享每 IP 15 分钟 20 次限流
- 比赛列表：按游戏、赛事、状态筛选；首页聚合各状态计数
- 赛前预测：选择胜者与合法比分；开赛前可修改 / 取消；提交历史写入 `prediction_history`
- 比赛详情：预测表单、已结算比赛的公开预测明细、对阵历史（H2H，按本场开赛前过滤，呈现赛前视角）
- 竞猜分享图：1080×1080 canvas 合成（MiSans 字体、主题配色、站点二维码），主页与个人中心可用
- 浅色 / 暗色主题：跟随系统 + localStorage 持久化；队标使用 PandaScore 暗色版，赛事 logo 自动匹配 `-dark` 变体
- **黑色赛事 logo 自动反色**：暗色模式下采样 logo 亮度，仅对深色 logo 应用反色，保证回看页可读
- 赛事回看：卡片 / 紧凑视图，赛程图（瑞士轮 / 双败 / 单败）完整呈现；吸顶阶段导航、LIVE 标记、未开赛时间角标
- **未来赛事预告**：赛事回看页展示配置天数内的远期赛事（赛事级信息，不导入远期比赛），跟随游戏筛选、可收起
- 赛事简称：管理端维护 `short_name`，移动端或名称过长时替代全名
- 队伍中心：队伍列表（搜索 / 游戏 / 排序）、统计、赛事履历与阶段名次、近期比赛
- 排行榜：总榜 / 赛事榜、分页、CSV 导出、用户得分明细
- 个人中心：预测记录（状态 / 游戏 / 赛事筛选）、统计、分享、预测公开开关、QQ 绑定、修改密码

### 管理后台 `/admin`

- 概览：用户 / 赛事 / 队伍 / 比赛 / 预测计数、同步状态、待结算提醒
- 用户管理：创建、改角色、重置密码、删除（默认 admin 受保护）
- 赛事 / 队伍 / 比赛 CRUD；赛事简称、级别（tier）、启用 / 禁用、手动上传 logo
- 比赛：创建 / 编辑、录赛果、弃权标记、预测开关、删除
- **赛果锁定**：手动录入赛果 / 弃权后 `result_locked=1`，PandaScore 同步不再覆盖
- 手动触发比赛同步；**赛事预告前瞻天数设置（7–365 天，默认 180）**、立即刷新赛事预告、逐项控制预告板块显示哪些赛事
- 预测记录查看与删除（删除后重建总分）
- 管理界面样式统一 `ops-` 前缀，避免 AdBlock 通用规则把整页误判为广告

### 积分规则

| 情形 | 得分 |
| --- | --- |
| 胜者预测错误 | **0 分** |
| 胜者正确、比分不完全一致 | **1 分** |
| 胜者与双方比分完全一致 | **满分**：BO1 = 1 / BO3 = 2 / BO5 = 3 |
| 弃权局（is_forfeit） | **0 分**（已结算、不挂起） |
| 比赛未结束 | `points_earned = NULL`（待结算） |

总分由 `predictions.points_earned` 全量重建（`recalculateUserScores()`），赛果修正、预测删除、比赛删除后都能自愈。

## 技术栈

| 层 | 技术 | 说明 |
| --- | --- | --- |
| 运行时 | Node.js ≥ 20 | 内置 `fetch`（同步服务） |
| Web 框架 | Express 4 | 多页静态 HTML + 服务端注入备案号 |
| 数据库 | better-sqlite3 | `data/database.sqlite`，同步 API，启用外键 |
| 鉴权 | jsonwebtoken | HS256，30 天；密钥支持落盘持久化；改密递增 `token_version` 使旧令牌失效 |
| 密码 | bcryptjs | 注册 / 重置 cost=10，默认管理员 cost=12 |
| 二维码 | qrcode | 分享图底部二维码（`/api/qrcode`） |
| 其他后端 | cors、dotenv | CORS 白名单（本地地址在非生产环境放行） |
| 前端 | 原生 HTML/CSS/JS | 无框架、无构建；`localStorage` 保存 token |
| 群机器人 | NapCat + 独立 Node 进程 | `bot/`，通过 HTTP 读取赛程、执行群内指令 |
| 测试 | node:test | 6 个测试文件、55 个用例：bracket / scoring / auth / admin / bot / bot-interactions |
| 部署 | PM2 + Nginx | 生产仅开放 80/443，Node 监听 127.0.0.1:3000 |

## npm scripts

| 命令 | 作用 |
| --- | --- |
| `npm start` / `npm run dev` | 启动 `server/index.js` |
| `npm run init-db` / `npm run migrate` | 建表 + 迁移 + 创建默认管理员 |
| `npm run sync:pandascore` | CLI 手动同步一次比赛 |
| `npm run backup` | 在线备份数据库到 `data/backups/`（`BACKUP_KEEP` 控制保留份数） |
| `npm run restore -- <file>` | 恢复指定备份（恢复前自动留存当前库） |
| `npm run cleanup:pandascore-duplicates` | 历史重复 external_id 清理（默认 dry-run） |
| `npm test` | 运行 `test/` 下 node:test 用例 |

## 设计取舍速记

- **无 ORM**：全部 prepared statement；`init-db.js` 用 `PRAGMA table_info` 探测列做幂等迁移。
- **前端无框架**：多入口 HTML + 独立脚本；公共能力收敛在 `shared.js`、`theme.js`、`tournament-logos.js`、`h2h.js`、`share.js`；`bracket.js` 保持纯函数便于单测。
- **近端/远期分离**：比赛高频同步只覆盖近端窗口；远期赛事只存赛事级预告（`tournament_previews`），6 小时低频刷新，避免海量请求与远期比赛污染积分。
- **后端可调配置**：管理后台设置写入 `app_settings`，重启不丢；环境变量仅作默认值兜底。
- **单进程**：限流、同步互斥、定时器均为内存态，部署假定 PM2 单实例。
- **安全内建**：logo 代理 SSRF 防护、输出统一转义、JWT 密钥落盘、上传文件 magic bytes 校验、HTML 禁用缓存防脏页面。
