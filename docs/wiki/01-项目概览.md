# 01 · 项目概览

## 项目定位

PRBET 是一个**中文电竞赛事竞猜站点**（无真实货币，纯积分玩法），核心闭环：

1. **同步**：定时从 PandaScore REST API 拉取 CS2 / Valorant 过去 1 天 ~ 未来 7 天的赛程与赛果，落库到 SQLite。
2. **竞猜**：用户注册登录后，在比赛开始前预测「胜者 + 双方比分」（BO1/BO3/BO5）。
3. **结算**：比赛结束后由系统（或管理员手动录入赛果）按积分规则结算，幂等可重算。
4. **排行**：依据积分生成总榜 / 赛事榜，支持 CSV 导出。

覆盖的游戏：CS2、Valorant（`game_type` 字段区分，同一套表与逻辑复用）。

## 功能特性

### 用户侧

- 注册 / 登录 / JWT 鉴权，登录接口限流防爆破
- 比赛列表：按游戏（CS2 / Valorant）、赛事、状态（未开始 / 进行中 / 已结束）筛选
- 赛前预测：选择胜者与 BO1 / BO3 / BO5 比分；开赛前可修改、可取消
- 比赛详情弹窗：对阵历史（H2H，近况 / 交手记录均按该场开赛前过滤，呈现赛前视角）、已结算比赛的预测详情（排名列表 + 命中率统计）
- 竞猜分享图：1080×1080 canvas 合成（MiSans 字体、主题配色、站点二维码），主页与个人中心均可生成、长按 / 下载保存
- 暗色 / 浅色主题：跟随系统偏好 + localStorage 持久化；队标与赛事厂牌 logo 自动换用暗色变体
- 赛事回看：赛程图（bracket）展示瑞士轮 / 双败淘汰 / 单败淘汰等完整赛制结构，吸顶阶段导航 + 移动端窄列布局；进行中比赛红框 LIVE 标记，未开赛比赛卡上方标开赛时间
- 赛事简称：管理端可维护 `short_name`，移动端或名称过长时替代全名展示
- 主页赛事组标题直达该赛事回看页；页脚 GitHub 仓库链接
- 队伍中心：队伍近期赛事、阶段名次（冠军/亚军/四强/八强）、比赛结果与胜率
- 排行榜（总榜 / 赛事榜、分页、CSV 导出、用户得分明细）
- 个人中心：我的预测（按状态筛选）、统计、竞猜分享、修改密码

### 管理后台 `/admin`

- 统计概览（用户 / 赛事 / 队伍 / 比赛 / 预测计数，同步状态）
- 用户管理（创建、改角色、重置密码、删除）
- 赛事 / 队伍 / 比赛 CRUD
- 手动触发 PandaScore 同步、查看同步记录
- 预测开关（单场 / 按赛事）、赛果录入、弃权标记、预测记录管理
- 赛事启用 / 禁用：禁用的赛事不在前台展示，后续同步会跳过其比赛状态与赛果更新，适合过滤无需竞猜的小型赛事

### 积分规则

| 情形 | 得分 |
| --- | --- |
| 胜者预测错误 | **0 分** |
| 胜者正确、比分不完全一致 | **1 分**（基础分） |
| 胜者与双方比分完全一致 | **满分**：BO1 = 1 / BO3 = 2 / BO5 = 3 |
| 弃权局（is_forfeit） | **0 分**（已结算、不挂起） |
| 比赛未结束 | `points_earned = NULL`（待结算） |

结算幂等：赛果修正后重新结算得到正确分数；用户总分由 `predictions.points_earned` 全量重建（`recalculateUserScores()`），避免增量累加导致的漂移。详见 [07-核心业务流程](./07-核心业务流程.md)。

## 技术栈

| 层 | 技术 | 说明 |
| --- | --- | --- |
| 运行时 | Node.js ≥ 20 | `engines` 约束；内置 `fetch`（同步服务用） |
| Web 框架 | Express 4 | 单应用、无模板引擎，HTML 由静态文件 + 服务端注入提供 |
| 数据库 | better-sqlite3 | SQLite 单文件 `data/database.sqlite`，同步 API，开启外键 |
| 鉴权 | jsonwebtoken | JWT（HS256，30 天有效期），密钥支持持久化 |
| 密码 | bcryptjs | 注册/重置 cost=10，默认管理员 cost=12 |
| 二维码 | qrcode | 分享图底部站点二维码（`/api/qrcode` 生成 PNG buffer） |
| 其他后端 | cors、dotenv | CORS 白名单、环境变量 |
| 前端 | 原生 HTML/CSS/JS | 无框架、无构建步骤；`localStorage` 保存 token |
| 测试 | node:test | `node --test`，目前覆盖 bracket.js 纯函数 |
| 部署 | PM2 + Nginx | 生产仅开放 80/443，Node 监听 127.0.0.1:3000 |

## 设计取舍速记

- **无 ORM**：全部裸 SQL（better-sqlite3 prepared statements），换取可读与零依赖；`init-db.js` 以 `PRAGMA table_info` 探测列的方式做幂等迁移。
- **前端无框架**：页面即多入口 HTML + 各自脚本；`shared.js` 提供公共认证与工具，`bracket.js` 保持纯函数以便 node:test 直接测试。跨页可复用的小部件独立成文件（`theme.js`、`tournament-logos.js`、`h2h.js`、`share.js`）。
- **分享图零依赖**：`share.js` 用原生 canvas + FontFace API 加载 MiSans woff2 合成分享图，不引入 html2canvas 等重依赖；二维码由后端 `/api/qrcode` 同源生成，避免跨域污染 canvas。
- **单进程**：限流用内存 Map，同步服务用模块级 `timer/running` 变量，部署假定 PM2 单实例（多实例需换 Redis 等共享存储）。
- **安全内建**：logo 代理只允许库内已注册 URL 并做 SSRF 校验；HTML 输出统一 `escapeHtml`；JWT 密钥落盘持久化；二维码接口限制协议白名单防滥用。
